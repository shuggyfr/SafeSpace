# SafeSpace

An interactive blog where people post problems, big or tiny, and people who've lived them leave advice.

This is a clickable prototype: a single `index.html` with sample posts. Anything you add is saved in your browser only (localStorage).

## Run it

Open `index.html` in a browser.

## What's in it

- Feed with topics and sorting (Fresh, Most relatable, Needs advice)
- Ask: post a problem, optionally anonymously
- Give advice, with a "Been through it" mark
- Reactions: "I've been there" on posts, "This helped" on advice
- The asker can mark the advice that sorted it
